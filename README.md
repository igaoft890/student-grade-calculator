# 📊 Student Grade Calculator

A simple Python application that calculates a student's average grade and determines whether the student has passed or failed.

## 📌 About

This project was developed as an introductory programming exercise to practice mathematical operations, user input, variables, and conditional statements in Python.

## ⚙️ Features

* Receives four student grades
* Calculates the final average
* Displays the average with two decimal places
* Determines whether the student passed or failed

## 🛠️ Technologies

* Python
* Google Colab

## 📚 Concepts Practiced

* Variables
* `input()`
* `float`
* Mathematical operations
* Conditional statements
* `if` and `else`
* Formatted output

## 📋 Passing Criteria

The student is considered approved when the final average is equal to or greater than **6.0**.
